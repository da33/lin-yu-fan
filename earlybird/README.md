# 萬能早鳥報名（學生端）

早鳥大冒險：9 個關卡、大約 1 分鐘的早鳥報名前端。學生掃 QR Code 進來填，資料落到 Google 試算表，之後由自動填寫程式登錄到學校早鳥系統。

- 線上網址：`https://da33.github.io/lin-yu-fan/earlybird/`
- 檔案：`index.html`（整個前端）、`apps-script.gs`（Google 試算表後台）

## 三步驟上線

1. **建立試算表後台**
   - 開一個新的 Google 試算表 → 擴充功能 → Apps Script → 貼上 `apps-script.gs` 全部內容。
   - 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分「我」、存取權「所有人」→ 部署。
   - 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
2. **填進前端**：打開 `index.html`，把網址貼到 `CONFIG.endpoint`，push 上去。
3. **做 QR Code**：每一場活動用不同的網址參數，之後可以統計成效：
   - `?src=中壢高中宣導` — 活動或學校名稱
   - `?src=升學博覽會&by=林祐凡` — 加上招生老師
   - 有 `src` 時會自動跳過「你是怎麼知道的」那一關。

## 早鳥大冒險：9 個關卡＝學校系統的必填欄位

學生只回答學校早鳥系統（saip.vnu.edu.tw/RevEnt）的必填欄位，每一關是地圖上的一站，答完拿一個道具、加經驗值，最後拿到可截圖分享的冒險者卡。
學校系統的欄位、選項、學校名單是實際讀取學校網站得來的（`bot/inspect.mjs`）。

| 站 | 學生看到的 | 學校系統欄位 | 互動 |
|---|---|---|---|
| 1 報到處 | 你的名字 | 姓名 | 最多 8 個字（學校系統上限） |
| 2 傳訊塔 | 手機 | 手機號碼 | 09 開頭 10 碼 |
| 3 守門員 | 通行證號碼 | 身分證字號 | 10 格即時亮起，檢查碼對了會顯示「驗證通過」 |
| 4 公會大廳 | 哪個公會（學校） | 縣市＋高中職校名 | 打兩個字跳出學校，點一下就好；縣市自動帶出 |
| 5 職業所 | 職業（科別） | 高中職就讀科別 | 常見科別一點就好，也可以自己打 |
| 6 小隊集合 | 小隊（班級） | 高中職就讀班級 | |
| 7 技能樹 | 統測群類 | 學制/統測群類 | 依科別自動猜，學生按「對」就好；不對才自己選 |
| 8 目標城堡 | 最想去的系 | 第一志願 | 系所卡片點一下 |
| 9 冒險契約 | 蓋章 | 個資同意 | 點印章蓋章 |

沒問學生、由程式自動帶的欄位：
- 高中職畢業年：116（學校系統預設值）
- 工讀、住宿：否（學校系統預設值）
- 早鳥訊息得知管道：萬能科大推薦人
- 萬能科大輔導(推薦)老師：QR Code 網址的 `by=`

選項文字要和學校系統**一字不差**：`CONFIG.departments`、`CONFIG.testGroups`、`CONFIG.schools` 分別對應 `bot/mapping.mjs` 的 `DEPARTMENTS`、`TEST_GROUPS` 與 `bot/schools.json`。
科別猜群類的規則在 `CONFIG.groupRules`。

## 第二段：自動登錄到學校系統（已寫好，尚未啟用）

`bot/` 裡的程式會讀試算表的「待處理」資料、對應欄位、填進學校系統，再把結果和截圖寫回試算表。
GitHub Actions 的 `earlybird-bot.yml` 要設定 `BOT_ENABLED=true` 才會定時執行，而且預設只「預演」（填好但不按申請）。
啟用步驟等 App 題目確定後再補上。

## 無障礙與遊戲化設計

- 一站一題，小鳥用對話框問問題；上方冒險地圖、經驗值、等級、道具，最後一張冒險者卡
- 點選題（學校建議、科別、群類、系所）點了就自動前往下一站；手機支援震動回饋
- 鍵盤：Enter 下一站、Tab 可達所有控制項
- 螢幕閱讀器：每站自動朗讀「第 N 站，共 M 站：問題」，錯誤訊息即時朗讀
- 「大字」按鈕、深色模式跟隨系統、減少動態效果跟隨系統
- 觸控目標 ≥ 48px、對比符合 WCAG AA
- 填到一半關掉頁面，再打開可「繼續上次」；沒網路會暫存並自動補送

## 沒有設定 endpoint 時

頁面進入「示範模式」：流程完整可試，資料只存在該支手機的瀏覽器裡（`localStorage` 的 `vnu-eb-demo`），完成畫面會標示。
