# 萬能早鳥報名（學生端）

一次一題、無障礙、約兩分鐘的早鳥報名前端。學生掃 QR Code 進來填，資料落到 Google 試算表，之後由自動填寫程式登錄到學校早鳥系統。

- 線上網址：`https://da33.github.io/lin-yu-fan/earlybird/`
- 檔案：`index.html`（整個前端）、`apps-script.gs`（Google 試算表後台）

## 三步驟上線

1. **建立試算表後台**
   - 開一個新的 Google 試算表 → 擴充功能 → Apps Script → 貼上 `apps-script.gs` 全部內容。
   - 部署 → 新增部署作業 → 類型「網頁應用程式」→ 執行身分「我」、存取權「所有人」→ 部署。
   - 複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
2. **填進前端**：打開 `index.html`，把網址貼到 `CONFIG.endpoint`，push 上去。
3. **做 QR Code**：每一場活動用不同的網址參數，之後可以統計成效：
   - `?src=中壢高中宣導` — 活動或學校名稱
   - `?src=升學博覽會&by=林祐凡` — 加上招生老師
   - 有 `src` 時會自動跳過「你是怎麼知道的」那一關。

## 和學校早鳥系統的欄位對應（116 學年度，saip.vnu.edu.tw/RevEnt）

學校系統的欄位、選項、學校名單是實際讀取學校網站得來的（`bot/inspect.mjs`）。

| App 的關卡 | 學校系統欄位 | 學校必填 | 怎麼對應 |
|---|---|---|---|
| 姓名 | 姓名 | ✓ | 最多 8 個字（學校系統上限） |
| 手機 | 手機號碼 | ✓ | 09 開頭 10 碼 |
| LINE ID（選填） | LineID | | 直接帶入 |
| Email | （學校系統沒有） | | 只存在試算表，方便聯絡 |
| 身分證字號 | 身分證字號 | ✓ | 檢查碼驗證 |
| 就讀學校 | 縣市＋高中職校名 | ✓ | 名單與學校系統相同，縣市自動帶出 |
| 科別 | 高中職就讀科別 | ✓ | 最多 15 字 |
| 班級 | 高中職就讀班級 | ✓ | 最多 15 字 |
| 年級 | 高中職畢業年 | | 高三→116、已畢業→115／114前；高一、高二不在這次早鳥範圍 |
| 統測群類 | 學制/統測群類 | ✓ | 23 個選項與學校一字不差 |
| 有興趣的系（最多 3 個） | 第一～第三志願 | 第一志願 ✓ | 依選擇順序 |
| 工讀／住宿 | 是否有工讀需求、是否有住宿需求 | | 一題問兩件事 |
| 特殊表現（選填） | 特殊表現 3 個勾選框 | | 直接對應 |
| 得知管道 | 早鳥訊息得知管道 | | 掃招生老師或活動 QR Code 進來的自動算「萬能科大推薦人」 |
| QR Code 的 `by=` | 萬能科大輔導(推薦)老師 | | 最多 4 個字 |
| 個資同意 | 個資使用聲明「我同意」 | ✓ | |
| （不問學生） | 高中職班導師 | | 試算表留「班導師」欄，老師可自己補 |

改題目時，選項文字要和學校系統**一字不差**：`CONFIG.departments`、`CONFIG.testGroups`、`CONFIG.schools` 分別對應 `bot/mapping.mjs` 的 `DEPARTMENTS`、`TEST_GROUPS` 與 `bot/schools.json`。
`QUESTIONS` 每一關一個物件；`enabled: false` 可關閉、`optional: true` 為選填。

## 第二段：自動登錄到學校系統（已寫好，尚未啟用）

`bot/` 裡的程式會讀試算表的「待處理」資料、對應欄位、填進學校系統，再把結果和截圖寫回試算表。
GitHub Actions 的 `earlybird-bot.yml` 要設定 `BOT_ENABLED=true` 才會定時執行，而且預設只「預演」（填好但不按申請）。
啟用步驟等 App 題目確定後再補上。

## 無障礙與遊戲化設計

- 一關一題，畫面只有一件事；進度條、關卡數、分數、稱號
- 鍵盤：Enter 下一關、數字鍵 1–9 選答案、Tab 可達所有控制項
- 螢幕閱讀器：每關自動朗讀「第 N 關，共 M 關：題目」，錯誤訊息即時朗讀
- 「大字」按鈕、深色模式跟隨系統、減少動態效果跟隨系統
- 觸控目標 ≥ 48px、對比符合 WCAG AA
- 填到一半關掉頁面，再打開可「繼續上次」；沒網路會暫存並自動補送

## 沒有設定 endpoint 時

頁面進入「示範模式」：流程完整可試，資料只存在該支手機的瀏覽器裡（`localStorage` 的 `vnu-eb-demo`），完成畫面會標示。
