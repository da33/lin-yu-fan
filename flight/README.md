# 東京搶票作戰室

TPE ⇄ TYO 2027/1/17 去、2/3 回。搶 Trip.com 限時秒殺（10/27 12:00 東京 999）的私人工具。

- 作戰頁：`https://da33.github.io/lin-yu-fan/flight/`（倒數、安裝步驟、作戰清單、行情、任何航空比價）
- 搶票腳本：`trip-grab.user.js`（Tampermonkey 使用者腳本，跑在自己已登入的瀏覽器）

## 腳本做什麼

1. **校時**：用 Trip.com 伺服器回應的 `Date` 標頭錯開相位取樣、取交集，誤差約 ±0.1 秒。
2. **盯盤**：在活動頁找同時含「地點關鍵字」和「價格」的卡片（橘框），以及卡片裡的搶購按鈕（綠色虛線框）。找錯就用「🎯 指定按鈕」手動鎖定，重整後也記得。
3. **開搶**：時間到、按鈕變成可按就點下去（開搶後 0.15 秒，吸收校時誤差）；開新分頁的連結改在本頁開，避免被瀏覽器擋。
4. **沒開就重整**：開搶 1.2 秒還沒變就重整，之後每次至少隔 4 秒、最多 25 次；出現安全驗證就停下來叫你。
5. **交棒**：按到就響鈴、語音、桌面通知；進到訂購頁提醒你確認日期、旅客、付款。登入、驗證、付款一律本人操作。

## 測過的情境（模擬活動頁，伺服器時鐘比本機快 2.3 秒）

| 情境 | 結果 |
|---|---|
| 時間到頁面自己跳價 | 校時誤差 0.02–0.07 秒；開搶後 0.20 秒點下去，進到訂購頁 |
| 要重整才會出現價格 | T+1.2 秒重整，重整後立刻點下去 |
| 已售完 | 停止並通知改打備案 |
| 30 秒演練 | 只回報會怎麼做，不點擊、不重整 |
| 導覽列也有「東京」字樣、旁邊有「大阪 999」誘餌卡 | 都沒被誤選 |
| 🎯 指定按鈕 | 點選時不會觸發原本連結；重整後仍鎖定同一顆 |

## 改場次

面板「設定」可以選三場預設，或自己改開搶時間（台灣時間）、地點關鍵字（`|` 隔開）、價格數字。預設場次寫在腳本最上面的 `PRESETS`。
改完腳本要把 `@version` 加一，Tampermonkey 才會自動更新。
