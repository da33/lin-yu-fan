安裝自動搶票腳本電腦版 Chrome／Edge，3 分鐘

  1. 裝 Tampermonkey 擴充功能

    免費的使用者腳本管理器，腳本就跑在你已登入的瀏覽器裡。

    Chrome 版Edge 版
  2. 打開「允許使用者指令碼」

    網址列輸入 chrome://extensions → Tampermonkey 的「詳細資料」→ 打開「允許使用者指令碼」。舊版 Chrome 沒有這個開關的話，改打開右上角「開發人員模式」。

  3. 安裝搶票腳本

    按下去，Tampermonkey 會跳出安裝頁，按「安裝」。已經裝過舊版的會跳出更新，一樣按安裝。

    ⚔ 安裝東京搶票助手
  4. 重新整理這一頁

    右下角出現「🤖 自動駕駛」面板、最上面的燈變綠就成功了。按一下面板的「🔊 點一下開聲音」，開賣時這頁也會響。

先講清楚

  • 全自動做到哪裡：雷達每天兩次掃各家官網的促銷消息、把開賣時間排進來 → 這頁在開賣前自動打開官網 → 校時到 0.1 秒 → 時間到還在倒數就重整，遇到排隊不重整 → 開賣就響鈴、說話、桌面通知。如果官網是「一張卡＋立即訂購」那種促銷頁，腳本會直接幫你按下去。登入、驗證碼、刷卡簡訊驗證一定要你本人，這也是它不會被官網當成機器人封鎖的原因。
  • 各家官網的訂位畫面都不一樣，選日期、選航班這一步請你自己按。腳本負責「準時、不漏掉、叫醒你」。
  • 特價艙位很少，熱門日期幾分鐘就沒了，而且多半是單程未稅價，行李、選位另外加價。2027 年春節是 2/6，2/3 很接近，有些促銷會把春節前後排除。
  • 電腦要醒著、Chrome 要開著這一頁。電腦睡著或這頁被關掉，自動駕駛就不會動。
