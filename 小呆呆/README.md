# 小呆呆

戴著 AirPods、手機鎖著放口袋，喊「小呆呆」它就醒。辦公室的 Mac 用 Claude 把事情做完，再用講的回報。私人工具。

**目前：第一版問答已經在 Rino 的 iPhone 上跑了**（2026-10-24）。喊「小呆呆」→ 叮 → 直接問 → 講完停一下 → 從 AirPods 聽到回答，簡單問題約 2.6 秒。

- 手機 App 在 `ios/`。
- 辦公室 Mac 的服務在 `mac/`。
- 交接說明在 `ios/CLAUDE.md`，最新決定記在 Notion Memory「小呆呆語音助理」。

## 第一個測試 App（`ios/`，已完成，App 現在會問答）

第一版只會一件事：手機鎖著、戴 AirPods，喊「小呆呆」就叮一聲。用來確認三件事：
- 手機鎖著能不能聽到「小呆呆」
- 一小時耗多少電
- AirPods 聽音樂時音質會不會變差

還不會回答問題、還不會連到 Mac，這三件確定可行才往下做。

### 到辦公室要做的事（第一次約 30–60 分鐘）

帶手機和充電線（要接 Mac）。

1. **Mac 要有 Xcode。** 打開「啟動台」找 Xcode。沒有的話，到 App Store 搜尋「Xcode」免費下載，檔案很大要等一陣子。裝好後打開一次，同意條款；問要裝哪些平台時勾 **iOS**。
2. **打開「終端機」，貼上這行按 Enter：**
   ```
   curl -fsSL https://raw.githubusercontent.com/da33/lin-yu-fan/main/%E5%B0%8F%E5%91%86%E5%91%86/ios/get.sh | bash
   ```
   它會把程式放到 `~/代碼程式/小呆呆/ios`、下載喚醒詞模型（約 36 MB），然後自動打開 Xcode。
3. **在 Xcode 登入 Apple ID：** 上方選單 Xcode → Settings → Accounts → 左下「+」→ Apple ID，由你自己登入。
4. **選簽名用的帳號：**
   - 左邊點最上面藍色的「XiaoDaiDai」。
   - 中間 TARGETS 點「XiaoDaiDai」，上方點「Signing & Capabilities」。
   - Team 選「你的名字 (Personal Team)」。
   - 只要選一次，之後更新也會記住。
5. **手機用線接上 Mac**，手機問「要信任這部電腦嗎」→ 信任。
6. **手機打開開發者模式：**
   - 手機「設定 → 隱私權與安全性 → 開發者模式」打開，手機會重開機，開機後再按一次確認。
   - 這個選項要接過 Xcode 才會出現。
7. **Xcode 上方中間選你的 iPhone，按左上角 ▶︎。** 第一次要下載元件、編譯，會比較久。
8. **手機第一次打開會說「不受信任的開發者」：** 到手機「設定 → 一般 → VPN 與裝置管理」→ 點你的 Apple ID → 信任。
9. **打開「小呆呆」，允許麥克風**，照 App 裡「怎麼測」做。測完按「分享測試紀錄」把紀錄傳給 Claude。

**每 7 天：** App 會過期打不開。回辦公室接上 Mac，在 Xcode 按一次 ▶︎ 就好。要更新到最新版，就再貼一次第 2 步那行。

### 驗證到哪裡

- **雲端驗證過的：**
  - 喚醒詞在 16 kHz（AirPods）和 48 kHz（iPhone 內建麥克風）的聲音都叫得醒，「發呆」「代代相傳」這類話不會誤醒。
  - App 可以編譯，模擬器 4 個測試全過（GitHub 的 Mac 雲端機器，Xcode 26.6）。
  - 實機版可以編譯。
  - 第 2 步的安裝指令在模擬的 Mac 環境跑通。
- **只能在你手機上確認的：**
  - 鎖螢幕還能不能一直聽。
  - AirPods 收音效果。
  - 耗電。
  - 免費 Apple ID 的安裝流程。
  - 「AirPods 高品質收音」開關的效果。

## 評估紀錄（雲端實測）

**喚醒詞**：用 sherpa-onnx 中文關鍵詞偵測，免訓練、本機跑、免費。測試是 8 種合成國語聲音各講 12 次，加上 10 分鐘真人國語。

| 叫法 | 叫一次就醒 | 真人說話中誤醒 | 相近的話會醒嗎 |
|---|---|---|---|
| 呆呆 | 78% | 0 次 | 「呆呆的」會醒、「代代」偶爾會 |
| 嘿呆呆 | 73% | 0 次 | 不會 |
| **小呆呆** | **91%** | 0 次 | 不會 |

用的是合成的大陸口音聲音，之後要用 Rino 本人的聲音、戴 AirPods 再測一次。

**語音辨識**

| 模型 | 台灣國語錯字率 | 速度 |
|---|---|---|
| Qwen3-ASR 1.7B | 3.8%（官方數字） | Rino 在 Mac 上實測：一句 6–10 秒的話約 0.6–0.9 秒 |
| whisper large-v3 | 7.8%（官方數字） | 雲端測 60 句真人國語，錯字率 8% |

兩個都會輸出簡體，要轉成繁體。轉換時只轉字形，不要用「台灣用語」模式，它會把「對象」轉成「物件」。

**語音**：Kokoro 念中文幾乎聽不懂，反向辨識錯字率 32–60%，不考慮。BreezyVoice 台灣腔好，但在 Mac 上比即時慢 10–13 倍，不能即時對話。

## 第一輪：claude-voice 方案（已不採用）

這個資料夾裡的 `install-mac.sh`、`start.sh`、`say-tts-server.mjs`、`test-mac.mjs`，是第一輪「在 Mac 前面用 claude-voice 對話」的測試包。**不要執行。**

不採用的原因：
- 它是終端機介面
- 它用 whisper，辨識不如 Mac 上已經有的 Qwen3-ASR
- Rino 平常人不在 Mac 旁邊

當時在雲端驗證出來、之後還用得到的發現：
- claude-voice 中文只認英文標點，要等 Claude 整段寫完才開始念
- 它講話時麥克風是關的，只能按空白鍵打斷
- Homebrew 的 whisper-cpp 已經不附 whisper-server
- `say-tts-server.mjs` 可以把 Mac 的「美佳」包成標準語音介面
